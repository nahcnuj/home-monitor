# DNS Latency Monitor — 画面設計

日付: 2026-07-25  
方針: **必要な機能を過不足なく載せ、読みやすく置く**。余白を詰めること・装飾を消すことが目的ではない。

## 1. この画面が提供する機能

| # | 機能 | ユーザーにとっての意味 |
|---|------|------------------------|
| F1 | **レイテンシ時系列グラフ** | DNS サーバー別の応答時間の推移（主役） |
| F2 | **表示範囲の選択** | グラフ 1 画面分の時間幅（30m〜3d） |
| F3 | **履歴の移動（パン）** | 履歴が範囲より長いとき、表示中の区間を時間軸上でずらす |
| F4 | **表示中区間の統計** | 測定数・平均・P95・最大（いま見ている窓だけ） |
| F5 | **エラー種別の内訳** | 同窓内の失敗の種類と割合 |
| F6 | **Uptime** | 同窓内の成功率 |
| F7 | **データ鮮度・エラー表示** | 最終データ時刻 / 読み込み失敗 |

## 2. 優先順位

1. グラフ（F1）— 最も大きく、最初に目に入る  
2. 統計（F4）— グラフのすぐ下で数値を確認  
3. エラー内訳 + Uptime（F5, F6）  
4. 表示範囲（F2）— 常に操作可能  
5. 履歴パン（F3）— 必要なときだけ表示  
6. 鮮度（F7）

## 3. レイアウト

### 全体

```
┌─────────────────────────────────────────────────────┐
│  タイトル + 説明              [ 30m 1h … 3d ]       │
│  最終データ: …（JST）                                │
│                                                     │
│  レイテンシ推移          30m · 開始 – 終了          │
│  ┌───────────────────────────────────────────────┐  │
│  │                                               │  │
│  │              グラフ（主領域）                   │  │
│  │                                               │  │
│  └───────────────────────────────────────────────┘  │
│  [履歴スクロール ※履歴が長いときだけ]                 │
│  測定数 · 平均 · P95 · 最大                         │
│                                                     │
│  エラー種別内訳                          Uptime     │
│  ┌───────────────────────────────────────────────┐  │
│  │  失敗種別の横帯                                 │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

### 余白・密度

- 詰め込みすぎない。セクション間・内側パディングは触りやすい程度を確保する  
- モバイルでもグラフがファーストビューの中心になる高さは維持する  
- PC（幅≥1000 かつ 高≥600）ではページスクロールなしで、グラフが残り高さを使う  

### 表示範囲とパン

- **表示範囲** = グラフ横幅が表す時間の長さ（ズーム）  
- **パン** = その幅の窓を履歴上でずらす  
- パン用コントロールは掴める高さ（おおよそ 20px 前後）。不要なら非表示  

### 統計・エラー

- 常に **いまグラフに表示している時間窓** に連動する  
- 統計はグラフ直下の横並び。エラーは下部の独立セクション  

## 4. 実装上の再利用

- データ取得・集計・Chart 描画・パンの数学は既存ロジックを接続してよい  
- マークアップとスタイルは本設計に合わせて定義する  

## 5. 受け入れ条件

- [ ] F1–F7 がすべて使える  
- [ ] グラフが画面の主役として十分な面積を持つ  
- [ ] 履歴が長いときパンができる  
- [ ] 統計・エラーが表示窓と一致する  
- [ ] 余白が極端に潰れていない（窮屈に感じない）
